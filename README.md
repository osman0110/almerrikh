# SuperStars of Tomorrow Flutter

Flutter conversion of the original Smart Sport Scribe / SSoT mobile web app.

## Run locally

```powershell
flutter pub get
flutter run -d chrome --web-port 5173
```

## Build for the current WAMP path

```powershell
flutter build web --base-href /smart-sport-scribe-main/build/web/
```

Local built URL:

```text
http://127.0.0.1/smart-sport-scribe-main/build/web/
```
